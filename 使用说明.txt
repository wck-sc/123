京东全屋家电选购顾问 V5 · AI 接入版

1. 本地预览：双击 index.html（3D 场景需联网；本地文件下部分浏览器限制 iframe/数据请求），只能体验规则式方案，不能连接 AI。
2. 真实 AI：需部署本文件夹至支持 Netlify Functions 的 Netlify 站点。注意：仅通过拖拽静态文件夹上传可能不会构建 Functions，推荐通过 Git 仓库导入部署，或使用 Netlify CLI 部署。
3. Netlify 后台 Site configuration > Environment variables 新建 OPENAI_API_KEY，填自己的 OpenAI API 密钥；可选 OPENAI_MODEL（默认 gpt-4.1-mini），保存后重新部署。
4. 不要把 API 密钥写入 HTML、前端 JS 或提交 Git；不要把密钥发给任何人。
5. 客户上传平面图后，AI 视觉模型识别房间的近似矩形区域，浏览器用 Three.js 重建可旋转概念模型；不是精确的墙体/门窗/水电/施工级 CAD 还原，尺寸需导购和设计师核对。
6. 商品池来自用户上传的626条部分目录（截至2026-11-01）；没有实时价格、库存，方案金额是预算分配而非报价。
7. 公网发布前应增加用户同意与隐私告知、速率限制、调用额度/成本控制、服务端滥用防护和上传文件保留政策。当前是功能验证原型，不建议直接开放给不受控公众。
